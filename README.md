Construo aplicações web, integrações de inteligência artificial e automações. Meu foco atual é o **LightIA**, um projeto em desenvolvimento para facilitar a criação de lojas virtuais com IA.

## 💡 LightIA | Projeto principal

O **LightIA** está sendo desenvolvido para ajudar empresas e empreendedores a criar e organizar sua presença no comércio digital com o apoio de inteligência artificial.

- **Proposta:** simplificar a criação de lojas virtuais e a organização de conteúdos e produtos.
- **Foco:** transformar tarefas complexas em uma experiência mais guiada e acessível.
- **Status:** em desenvolvimento. Funcionalidades e experiência seguem em evolução.

## 🛠️ Projetos públicos em evolução

### [Audio Neural Podcast](https://github.com/natanrocha2672-droid/audioneuraupodcast)

Aplicação web para transformar temas, textos e PDFs em roteiros de podcast e áudio com vozes neurais. O projeto explora geração de roteiro e áudio com a API da OpenAI.

**Tecnologias:** React, Vite, Tailwind CSS e funções serverless.  
**Status:** MVP em evolução.

### [Pexels MCP](https://github.com/natanrocha2672-droid/pexels-mcp)

Servidor MCP em Python para pesquisar fotos e vídeos do Pexels, explorando a integração entre ferramentas de IA e serviços externos.

**Tecnologias:** Python, Model Context Protocol (MCP) e API do Pexels.  
**Status:** projeto experimental em evolução.
